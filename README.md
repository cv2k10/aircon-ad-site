# CoolNest landing page

A responsive recreation of `mockup/Stay Cool, Live Better.png` using plain HTML, CSS, and JavaScript.

Run `python3 -m http.server 5173` from this folder and open http://localhost:5173.

The room background and transparent wave mark were reconstructed with the built-in image generation tool. Original generated PNG assets are retained in `assets/`; the page uses a WebP background. Headline, navigation, temperatures, buttons, and feature icons remain editable HTML/SVG. Arial is used as a close available font substitute.

Navigation, search, model exploration, and installation buttons open accessible dialogs. Catalog, checkout, booking, and support integrations were not supplied and are clearly identified as unconnected.

Asset briefs: faithfully reconstruct the reference room without navigation, text, buttons, icons, or temperature labels; extract the cyan/blue wave symbol onto transparency without lettering.
